# Code of Conduct

Short and enforceable: be a professional.

- Assume competence and good faith in others.
- Critique code, designs and decisions — not people.
- No harassment, discrimination or abusive language, in issues, PRs, reviews or
  any project channel.
- Keep discussions technical; keep disagreements about the artifact.

Maintainers may edit, close or remove contributions and comments that violate
this, with an explanation where reasonable. Report problems by opening a
private GitHub security advisory marked "conduct" or contacting a maintainer
directly.

(If the project grows, this will graduate to the full Contributor Covenant.)
